# ThreadSaver

A single-page web app for creating and saving Threads post mockups as PNG images.

## Features

- **Paste a Threads post** and render it in an authentic-looking Threads UI
- **Download as PNG** — saves a clean screenshot of the post card
- **Dark / light mode** toggle
- **Show/hide timestamp** on the post
- No backend, no installs — runs entirely in the browser from a single HTML file

## Usage

Open `index.html` in any modern browser. Paste your Threads content, customize the card, then hit Download to save the PNG.

## Built With

- React 18 (via CDN)
- Tailwind CSS (via CDN)
- html2canvas
